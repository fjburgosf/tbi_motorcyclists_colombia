# TBI Mortality Among Motorcyclists in Colombia, 2015–2024

Reproducible analysis pipeline for the manuscript:

> *"Traumatic Brain Injury Mortality Among Motorcyclists in Colombia, 2015–2024:
> National Trend, Territorial Inequality, and a Data-Comparability Warning for
> Vital Statistics Research"* — submitted to *Safety* (MDPI).

**Author:** Francisco Burgos-Florez · Universidad Nacional de Colombia, Sede La Paz,
Cesar, Colombia · fjburgosf@unal.edu.co

---

## Repository contents

```
scripts/    Analysis pipeline (13 scripts, numbered in execution order)
requirements.txt  Python dependencies
```

All outputs (figures, tables, model results) are **not** included — they are
generated by running the pipeline. Raw microdata (~3.7 GB) are also excluded;
they are downloaded automatically in Step 3.

| Source | Resource ID / URL | Period |

## How to reproduce

### Requirements

- Python 3.12
- Internet access (scripts download raw data automatically)

### Step 1 — Clone and install dependencies

```bash
git clone https://github.com/fjburgosf/tbi_motorcyclists_colombia.git
cd tbi_motorcyclists_colombia
pip install -r requirements.txt
```

### Step 2 — Create the required directory structure

```bash
mkdir -p data/raw data/interim data/processed results/exploratory results/primary results/robustness figures tables
```

### Step 3 — Download and inspect raw data

```bash
python scripts/03_inspect_data.py
python scripts/03b_inspect_data_panel_2015_2024.py
```

Downloads Medicina Legal and DANE microdata into `data/raw/` and runs
initial audits. Expect ~3.7 GB and several minutes depending on connection speed.

### Step 4 — Clean and filter

```bash
python scripts/04_clean_data.py
```

Filters both Medicina Legal datasets to motorcyclists and standardises
categorical variables. Outputs: `data/interim/medlegal_moto_fatal.csv`,
`data/interim/medlegal_moto_nofatal.csv`.

### Step 5 — Construct analysis variables

```bash
python scripts/05_construct_variables.py
```

Adds population denominators (DANE projections) and builds the analysis
datasets for RQ1 (trend/territorial) and RQ2 (case-fatality). Outputs go to
`data/processed/`.

### Step 6 — Linkage audit (optional, diagnostic only)

```bash
python scripts/06_link_data.py
```

Audits the ecological linkage between DANE and Medicina Legal by
department × year. Results go to `results/exploratory/`.

### Step 7 — Descriptive analysis

```bash
python scripts/07_descriptive_analysis.py
```

Generates the national series and departmental rates used in Table 1.
Outputs: `results/exploratory/rq1_serie_nacional.csv`,
`results/exploratory/rq1_tasas_departamento.csv`.

### Step 8 — Primary models

```bash
python scripts/08_primary_model.py
```

Fits the three main models:
- **H1** Negative binomial trend (national, 2015–2024)
- **H2** Territorial heterogeneity (Poisson, departmental)
- **H3** Case-fatality logistic + Bayesian mixed GLM

Results go to `results/primary/`.

### Step 9 — Robustness and sensitivity analyses

```bash
python scripts/09b_runt_sensitivity.py       # RUNT motorcycle-fleet denominator
python scripts/09c_rq2_profile_bounding.py   # RQ2 descriptive profile + selection bounds
python scripts/09d_referee_revisions.py      # TBI-specific trend; DANE 2015–2021 IRR
```

Results go to `results/robustness/`.

### Step 10 — Figures

```bash
python scripts/10_figures.py
```

Generates Figures 1–3 and S1 in `figures/`.

### Step 11 — Tables

```bash
python scripts/11_tables.py
```

Generates Tables 1–3 in `tables/`.

## Inference ceiling

All results are **descriptive, associational, and ecological** — no causal
claims are made. Individual-level inference is not supported by the data linkage.
