# TBI Mortality Among Motorcyclists in Colombia, 2015–2024

Reproducible code and documentation for the manuscript *"Traumatic Brain Injury
Mortality Among Motorcyclists in Colombia, 2015–2024: National Trend, Territorial
Inequality, and a Data-Comparability Warning for Vital Statistics Research"*
(submitted to *Safety*, MDPI).

**Author:** Francisco Burgos-Florez — Universidad Nacional de Colombia, Sede La Paz,
Cesar, Colombia · fjburgosf@unal.edu.co

## What this repository contains

| Path | Contents |
|---|---|
| `scripts/` | Full analysis pipeline (download → clean → construct → model → figures/tables) |
| `manuscript/` | Manuscript (`manuscript_safety_final_EN.md`) and formatted references |
| `figures/` | Figures 1–3 and S1 (generated by `scripts/10_figures.py`) |
| `tables/` | Tables 1–3 and S1–S3 (generated by the pipeline) |
| `docs/` | Methodology, definitions, decisions, analysis and results logs |
| `results/` | Model outputs (exploratory / primary / robustness) |

Raw microdata (~3.7 GB) are **not** included: they are public and are downloaded by
the scripts. See `DATA_SOURCES.md` for every source, URL, resource ID and access date.

## Data sources (all public)

- **Medicina Legal** fatal (`s65h-7665`) and non-fatal (`ezhf-hscf`) transport-injury
  microdata — datos.gov.co (Socrata API).
- **DANE** vital-statistics death microdata (2015–2024) and departmental population
  projections — DANE microdata portal.
- **RUNT2.0** registered-motorcycle fleet by department (`u3vn-bdcy`) — datos.gov.co.

## Reproducing the analysis

Requires Python 3.12.

```bash
pip install -r requirements.txt
# Scripts are numbered in execution order:
python scripts/04_clean_data.py
python scripts/05_construct_variables.py
python scripts/08_primary_model.py        # trend, territorial, case-fatality models
python scripts/09b_runt_sensitivity.py    # RUNT exposure-denominator sensitivity
python scripts/09c_rq2_profile_bounding.py# RQ2 profile + selection bounding
python scripts/09d_referee_revisions.py   # TBI-specific trend, DANE 2015-2021
python scripts/10_figures.py              # Figures 1-3, S1
python scripts/11_tables.py               # Tables 1-3
```

Key numbered scripts (some template steps required no dedicated script):
`03/03b` inspection, `04` cleaning, `05` variable construction, `06` linkage audit,
`07` descriptive, `08` primary models, `09b–09d` robustness, `10` figures,
`11` tables, `13` reference formatting.

## Inference ceiling

Descriptive, associational and ecological only — **no causal claims**. See
`docs/DECISIONS.md` (D002) for the rationale.
